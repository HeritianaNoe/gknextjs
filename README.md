# Katro Web — Next.js

Lalao **Katro** (lalao nentim-paharazana malagasy) natao tamin'ny **Next.js** + React + Tailwind CSS.

## Fampiasana

```bash
cd katro-web
npm install
npm run dev
```

Avy eo sokafy http://localhost:3000

## Features

- Lalao 2 mpilalao (olona vs olona) na vs solosaina (Easy / Medium / Hard)
- 8 na 12 lavaka isaky ny mpilalao
- Lalan-dava: Haavia / Havanana
- Animation amin'ny sowing
- Capture (maka voa)
- UI amin'ny teny Malagasy + Anglisy

## Structure

- `src/lib/katro.ts` — lojika ny lalao (Board, AI)
- `src/components/KatroGame.tsx` — UI sy game loop
- `src/app/page.tsx` — pejy lehibe
